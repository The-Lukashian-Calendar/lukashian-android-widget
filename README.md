This widget displays the current time, day and year of the Earth or Mars instance of the
Lukashian Calendar.

On some devices, there is a limit on how often a widget can update itself on the screen.
If beeps update in an irregular pattern, you can always tap the widget to update it.

To download it onto your Android device, please visit the
[Google Play Store](https://play.google.com/store/apps/details?id=org.lukashian.calendarwidget).

For more information on the calendar mechanism itself, please visit
[lukashian.org](https://www.lukashian.org).
